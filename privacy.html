Privacy Policy — KnowWow Uploader

Last updated: 27 October 2026

Who uses this tool

KnowWow Uploader is used only by the owner of the KnowWow - เรื่องราวน่ารู้ channel to upload that channel's own videos. It is not a public service and has no other users.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data is accessed

  • The OAuth access token for the owner's own Google account, used to upload videos to the owner's channel.
  • Basic information about the owner's own channel (channel name and ID), used to confirm the correct channel.
  • Video files, titles, descriptions, thumbnails and publish times prepared by the owner.

How data is stored and shared

The access token is stored only in a file on the owner's own computer. No data is sent to any server other than Google's YouTube API, and no data is sold, shared with third parties or used for advertising. No cookies or analytics are used.

Data retention and deletion

The tool keeps no database. The only stored item is the OAuth token file on the owner's computer, kept until the owner deletes it or revokes access. Revoking access (below) or deleting that file removes all stored data immediately. Videos uploaded to YouTube stay on the owner's channel until the owner deletes them in YouTube Studio. Deletion requests can also be sent to the contact email below and are handled within 7 days.

How to revoke access

Access can be revoked at any time from the Google security settings page: https://myaccount.google.com/permissions. Deleting the token file on the owner's computer also removes the stored access.
